# SCAD - Lab Assignment 1 (Python)

Simple Python programs for SCAD Lab Assignment 1.

## Tasks

| File | Description |
|---|---|
| `task1_positive_negative_zero.py` | Check whether an integer is positive, negative, or zero |
| `task2_percentage_grade.py` | Calculate percentage and grade from marks of five subjects (Physics, Chemistry, Biology, Mathematics, Computer) |
| `task3_triangle_type.py` | Check whether a triangle is equilateral, isosceles, or scalene |
| `task4_authentication.py` | Dummy authentication system with email and password validation |
| `task5_leap_year.py` | Check whether a year is a leap year or not |

## How to Run

```bash
python task1_positive_negative_zero.py
python task2_percentage_grade.py
python task3_triangle_type.py
python task4_authentication.py
python task5_leap_year.py
```
